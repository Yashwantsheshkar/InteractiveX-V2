# 🚀 InteractiveX V2 – Social Media iOS App with SwiftUI

**InteractiveX V2** is a feature-rich social media iOS app designed with modern gesture-driven interactions, smooth custom animations, and secure user flows. Built using SwiftUI and powered by local persistence, it offers a fast, clean user experience even offline.

---

## 🧩 Features

- 🔁 **Gesture-Based Interactions** for seamless user experience  
- ✨ **Custom Animations** for fluid navigation and transitions  
- 🔐 **Secure Authentication** using `@AppStorage`  
- ☁️ **Real-Time Content Updates** with async API integration  
- 💾 **Local Data Persistence** with **Core Data**, syncing efficiently with cloud services  
- 🌓 **Dark Mode Support**  

---

## 🛠️ Tech Stack

- **Swift 5**
- **SwiftUI**
- **MVVM Architecture**
- **Core Data** (Persistence)
- **AppStorage** (Authentication handling)
- **Async/Await API Calls**
